# Apple-Style Theme Manager Configuration

```json
{
  "auto_backup": true,
  "apply_to_all_card_templates_by_default": false,
  "show_unsupported_note_types": true,
  "default_preset": "auto"
}
```

## Options

- `auto_backup`: Keep this `true`. Turning it off is unsafe.
- `apply_to_all_card_templates_by_default`: Keep this `false` unless you understand Anki note/card templates.
- `show_unsupported_note_types`: Reserved for future filtering.
- `default_preset`: Reserved for future preset preselection.
