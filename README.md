## 🎯 Overview

Apple Theme Manager is a powerful Anki add-on that allows you to:

- Apply custom card themes for enhanced visual learning.
- Manage multiple **preset styles** including **Enhanced Cloze 2.1 v2**.
- Seamlessly edit `presets.py` to add your own templates and fields.
- Auto-detect note types and apply theme files for both front and back.
- Keep your Anki decks visually consistent across languages.

---

## ⚡ Features

- **Enhanced Cloze support** (`cloze_21_v2`, `cloze_21_v2plus`)
- Multiple built-in presets:
  - Basic: Front / Back
  - Basic + Additional Info
  - Code Output / Code Refactor
  - Interactive Coding
  - Image Occlusion
- Automatic CSS loading (`shared.css`)
- Safe integration without overwriting original Anki note templates
- Backup management and `.gitignore` ready

## 🛠 Installation

1. Download or clone this repo:

bash```
git clone https://github.com/itsnickp/apple_theme_manager_ankiaddon.git```

2. Move apple_theme_manager_ankiaddon folder to your Anki add-ons directory:
Windows: %APPDATA%\Anki2\addons21\
MacOS: ~/Library/Application Support/Anki2/addons21/
Linux: ~/.local/share/Anki2/addons21/

3. Restart Anki and check the Theme Manager in your Tools menu.

💡 Usage
Open Apple Theme Manager from Tools → Add-ons.
Select the desired preset for your note type.
Click Apply Theme to update the front and back templates.
Optional: Modify presets.py to create custom themes with your own fields.
